# Juego de Triqui

Este proyecto es un juego básico de triqui (tres en raya) desarrollado con HTML, CSS y JavaScript.

## Características
- Juego para dos jugadores (X y O)
- Interfaz simple
- Detecta ganador

## Archivos
- index.html: estructura del juego
- styles.css: diseño
- script.js: lógica del juego
